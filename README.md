# AWS End-to-End CI Pipeline Project

This project demonstrates an end-to-end CI pipeline using:

- GitHub
- AWS CodePipeline
- AWS CodeBuild
- Docker
- Docker Hub

## Workflow

GitHub Push → CodePipeline → CodeBuild → Docker Build → Docker Hub Push

## Project Files

- app.py
- Dockerfile
- buildspec.yml
- requirements.txt
